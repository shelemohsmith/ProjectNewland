# Project Newland

This repository contains the source for the `Project Newland` website.

## Publishing the site

To publish this site with GitHub Pages:

1. Open the repository settings on GitHub.
2. Go to the **Pages** section.
3. Select the `main` branch and the `/ (root)` folder.
4. Save the settings.

Once enabled, the site will be served from the repository root and display the correct project name.
